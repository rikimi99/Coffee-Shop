# Juniper Coffee Landing Page

A responsive, editorial-style landing page for Juniper Coffee, a neighborhood coffee house in Brooklyn, New York.

## About

The website presents Juniper Coffee's story, featured drinks and pastries, opening hours, location, and primary calls to action. It uses warm cream tones, deep green accents, bold editorial typography, and full-width photography to create a welcoming, premium café atmosphere.

## Features

- Responsive desktop, tablet, and mobile layouts
- Accessible semantic navigation and image descriptions
- Smooth in-page navigation
- Hero, story, menu, visit, and footer sections
- Hover and focus states
- External Google Maps directions link

## Preview

Open `index.html` directly in a browser, or run a local server from this directory:

```bash
python3 -m http.server 4173
```

Then visit [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Files

- `index.html` — Page structure and content
- `styles.css` — Layout, typography, colors, and responsive styles
- `images/` — Local project assets

## Notes

The page uses Fraunces and DM Sans from Google Fonts. Photographs are loaded from Unsplash and require an internet connection. The café name, address, hours, menu items, prices, and social links are presentation content and can be replaced with client-approved details.
