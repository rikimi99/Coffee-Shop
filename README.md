# Juniper Coffee Landing Page

A responsive, editorial-style landing page for Juniper Coffee, a neighborhood coffee house in Brooklyn, New York.

## About

The website presents Juniper Coffee's story, featured drinks and pastries, opening hours, location, and primary calls to action. It uses warm cream tones, deep green accents, bold editorial typography, and full-width photography to create a welcoming, premium café atmosphere.

## Page sections

- Hero — Coffee house introduction and featured opening hours
- Story — Juniper Coffee background and neighborhood positioning
- Menu — Featured drinks and a house-baked pastry
- Visit — Address, opening hours, and directions
- Footer — Brand and social media links

## Included details

- Fully responsive desktop, tablet, and mobile layouts
- Semantic navigation and descriptive image alt text
- Smooth anchor navigation
- Hover and keyboard-focus styling
- Google Maps directions link
- Local CSS with Google Fonts loaded from the web

## Preview locally

Run a local server from the project directory:

```bash
python3 -m http.server 4173
```

Then visit [http://127.0.0.1:4173](http://127.0.0.1:4173).

You can also open `index.html` directly in a browser.

## Project files

- `index.html` — Page structure and content
- `styles.css` — Layout, typography, colors, and responsive styles
- `README.md` — Project overview and preview guide

## Content and assets

The project is currently a static HTML and CSS website with no build process or JavaScript dependencies.

The page uses Fraunces and DM Sans from Google Fonts. Photographs are loaded directly from Unsplash URLs and require an internet connection. No local image assets are currently stored in the project.

The café name, location, opening hours, menu items, prices, and social links are presentation content and should be replaced with client-approved details before publication.
